# Улучшения и эксперименты (ведём в `dev`)

На GitHub Pages уходит `dev` (так стоит в `pages.yml`); `main` — снимок проверенного для отката.
Вся новая работа и рискованные опыты идут в `dev`. В `main` попадает только проверенное — её публикует сайт.

## Правила
1. Каждый эксперимент — отдельный коммит с понятным сообщением (`свет: ручное включение`, а не `fix`).
2. Перед переносом в `main`: `./test_all.sh --fast` (сборка + все автопроверки, код возврата ≠ 0 при провале).
3. Игру не ломаем: `index.html` собирается из `parts/*` (`./build.sh`), руками не правим.
4. Если эксперимент провалился — откат `git revert`, а не «закомментировать и забыть».
