# Ветка `dev` — улучшения и эксперименты

`main` остаётся «релизом»: то, что уходит на GitHub Pages (workflow деплоит только `main`).
Вся новая работа и рискованные опыты — здесь, в `dev`. Проверили на `dev` → переносим в `main` коммитом.

## Правила ветки
1. Каждый эксперимент — отдельный коммит с понятным сообщением (`свет: ручное включение`, а не `fix`).
2. Перед переносом в `main`: `./build.sh` + `node test2_core.js` + `node test3_dom.js` + `node tools/check_*.js`.
3. Игру не ломаем: `index.html` собирается из `parts/*` (`./build.sh`), руками не правим.
4. Если эксперимент провалился — откат `git revert`, а не «закомментировать и забыть».
