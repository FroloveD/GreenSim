# Проверки и две ветки — короткая шпаргалка

## 1. Одна команда — все автопроверки

Linux / macOS / Git Bash:

```
./test_all.sh --fast
```

Windows PowerShell (из папки с игрой):

```
.\test_all.ps1 --fast
```

Скрипт сначала делает `bash build.sh` (чтобы `index.html` не отстал от `parts/*`), потом гоняет раннер. Если хоть одна проверка упала — код возврата 1, и это видно в консоли словами `ПРОВАЛЕНО: N`.

Флаги:

| команда | что делает | время |
|---|---|---|
| `node tools/run_all.js` | всё, включая 90-дневные прогоны | ~4 мин |
| `node tools/run_all.js --fast` | без долгих прогонов | ~3 мин |
| `node tools/run_all.js --no-browser` | только Node, браузер не нужен (для CI) | ~15 с |
| `node tools/run_all.js --browser-only` | только Playwright | зависит от набора |

Перед первым браузерным прогоном один раз:

```
npm i playwright-core @sparticuz/chromium
```

Сервер на `:8080` раннер поднимает сам (`tools/serve.js`) и гасит в конце — руками ничего запускать не надо.

## 3. Ветки: работаем в `dev`, публикуем из `main`

`dev` — рабочая ветка **и то, что публикуется на сайте**: в `pages.yml` стоит `branches: [ dev ]`.
`main` держим как проверенный снимок для отката. Автопроверки (`tests.yml`) бегут на обе ветки.

Пушим изменения:

```
git checkout dev
git add -A
git commit -m "что сделали"
git push origin dev
```

Первый раз на новой машине — с привязкой ветки: `git push -u origin dev`.

Релиз-снимок в `main` (по желанию, для отката):

```
git checkout main
git merge dev
git push origin main
```

После пуша в `dev` на GitHub сами зеленеют два job'а: `build` (сверяет `index.html` со сборкой из `parts/*`)
и `deploy` (Pages). Сайт: https://froloved.github.io/GreenSim/

## 4. Досветка: что изменилось

- Кнопка **«Досветка»** под сценой включает и выключает свет при любой лампе (лента, лампа на стойке, LED) — раньше она требовала именно LED за 2800 € и врала «купите».
- **Клик по светильнику в сцене** тоже переключает: светильники видны всегда, когда лампа куплена (тёмный корпус = выключена, тёплый = горит), наведение показывает карточку с состоянием.
- «Параметры» и кнопка под сценой идут через одну функцию, поэтому не расходятся; состояние попадает в сохранение.
- Теплица больше не остаётся тёмной при одной ленте: сцена считает свет как «лампа или лента».

## 5. Таймеры и будильник

- «Параметры» → карточка **«Таймеры и автоматизация»**: свет по расписанию, полив по датчику (с целью влаги), CO₂ по окну, полная автоматизация.
- Свободный сезон — всё сразу. Кампания открывает по шагу: глава 1 свет → глава 2 полив (только грунт/кокос) → глава 3 CO₂ (нужен клапан) → глава 4 полная автоматизация (нужен климат-контроллер).
- Ручная кнопка «Досветка» сильнее расписания: нажали — таймер света выключился.
- Будильник досветки теперь виден: строка в панели рисков (она сортируется, плохое вперёд) и всплывающее напоминание раз в сутки. Сам лампу не переключает.

## 6. Полив: что изменилось

- Влажность субстрата видна в панели датчиков («влага 55 %») — это показание датчика, оно может врать и калибруется.
- Кнопка **«Полить 55 %»** под сценой: одна доза +15 п.п., вода списывается из бака (18 л на балконе, 1,8 м³ на теплицу 400 м²).
- **Клик по горшку** в сцене поливает грядку; грунт темнеет от воды, карточка под курсором показывает влагу и дозу.
- Сухо ниже 32 % — водный стресс и минус к урожаю (без полива 1006 кг против 1330 кг за 60 дней); перелив выше 88 % — корневая гниль. Оба состояния видны алертами и оба устранимы.
- Автополива нет: только руки игрока, напоминают алерты.
